# Model & Asset Licenses

This project auto-downloads a small set of free sample glTF models from the Khronos glTF Sample Models collection. These sample models are provided by Khronos and are suitable for prototyping and testing.

Included references (manifest.json):

- RobotExpressive - https://github.com/KhronosGroup/glTF-Sample-Models/tree/master/2.0/RobotExpressive (License: Public Domain/CC0 as provided by Khronos)
- Fox - https://github.com/KhronosGroup/glTF-Sample-Models/tree/master/2.0/Fox (License: Public Domain/CC0)
- CesiumMan - https://github.com/KhronosGroup/glTF-Sample-Models/tree/master/2.0/CesiumMan (License: Public Domain/CC0)

If you prefer other assets (different license or higher fidelity models), replace the URLs in public/models/manifest.json and run `node scripts/fetch-assets.js`.
